---
title: "Import customers from a CSV"
description: "Upload a CSV to create or update customers and companies, preview matches with a dry run, and roll back an import within 7 days."
---

Open **Customers**, switch to **People** or **Companies**, and click **Import**. Your role must allow writing customers and managing imports.

## CSV format and limits

Upload a CSV with a header row, up to 10 MB and 50,000 rows. Each teammate can upload up to 10 files per hour.

| Import type | Supported columns | Required on every row |
| --- | --- | --- |
| **People** | **Email**, **Name**, **External ID**, **Phone**, **Company name**, **Company domain**, **Tags**, any custom attribute | Email or External ID |
| **Companies** | **Name**, **Domain**, **External ID**, **Tags**, any custom attribute | Domain or External ID |

dimmi auto-maps columns whose headers match standard fields or attribute keys/labels (such as `email`, `full_name`, `user_id`, `company`, or `tags`).

- **Tags:** separate multiple tags with `,`, `;`, or `|` (up to 20 per row). Missing tags are created automatically.
- **Numbers:** commas like `1,250` parse as `1250`.
- **Yes or no:** accepts `true`, `yes`, `y`, `1`, `false`, `no`, `n`, or `0`.
- **Dates:** accepts `2026-03-01`, `2026-03-01 14:30:00`, or ISO 8601 with a time zone.
- **New attributes:** automatically created as text or number based on the first value seen.
- **Blank cells:** ignored. An import never erases existing data.

## How rows match existing records

People match by external ID first, then by verified email. Companies match by external ID first, then by domain. If a person row includes a company name or domain, dimmi finds or creates that company and links them. To put someone in several companies, separate them with `;` or `|` in the same cell, for example `Acme; Globex`. The first one becomes their default company, and domains pair with names by position.

Use **When someone is already here** to pick your behavior: **Update them** fills in values from your CSV, while **Leave them as they are** skips matching rows.

Before anything changes, the dry run previews counts for **New**, **Updated**, **Skipped**, and **Problems**.

## Handle failed rows

Bad rows never block the rest of your file. After the import finishes, download the error report CSV listing each failed row, its line number, and the reason. dimmi keeps up to 10,000 failed rows and deletes your uploaded file after 30 days.

## Undo an import

Teammates with rollback permission can undo a completed import once within 7 days from the past imports list inside the **Import** window.

- **New records removed:** deleted unless someone edited or tagged them since, or the customer started a conversation.
- **Updated fields restored:** reverted to their old values unless edited again afterward.
- **Added tags removed:** stripped back off the affected records.
