description: "Install dimmi/dimmi-laravel to add the messenger, identity tokens, the REST API client and webhook handling to a Laravel app."
---

`dimmi/dimmi-laravel` works with Laravel 10, 11 and 12 on PHP 8.2 or later, and includes the [PHP SDK](/developers/sdks/php/).

```bash
composer require dimmi/dimmi-laravel
php artisan dimmi:install
```

`dimmi:install` publishes `config/dimmi.php` and adds these keys to `.env` and `.env.example`:

```bash title=".env"
DIMMI_BASE_URL=https://app.trydimmi.com
DIMMI_TOKEN=<api_token>
DIMMI_WORKSPACE=
DIMMI_APP_ID=wgt_<app_id>
DIMMI_IDENTITY_SECRET=dmi_idsec_<secret>
DIMMI_IDENTITY_KID=isk_<key_id>
DIMMI_WEBHOOK_SECRET=whsec_<secret>
```

| Key | Value |
| --- | --- |
| `DIMMI_BASE_URL` | Your dimmi address on a self-hosted install. |
| `DIMMI_TOKEN` | An [API token](/developers/api/authentication/). |
| `DIMMI_WORKSPACE` | Leave empty. An API token works in its own workspace. |
| `DIMMI_APP_ID` | The messenger app ID (`wgt_...`) from **Settings → Messengers**. |
| `DIMMI_IDENTITY_SECRET`, `DIMMI_IDENTITY_KID` | A secret from [identity verification](/developers/messenger/identity-verification/). |
| `DIMMI_WEBHOOK_SECRET` | The signing secret of your [webhook endpoint](/developers/webhooks/verify-signatures/). |

To check the keys against dimmi, run `php artisan dimmi:test`. It calls the API, signs an identity token, and exits non-zero when a check fails.

## Show the messenger

```blade title="resources/views/layouts/app.blade.php"
    @dimmiMessenger
</body>
```

The directive signs a token for `auth()->user()` and shows the anonymous messenger to guests. By default the token carries the user's id, `email`, `name`, `email_verified_at` and `created_at`.

| To | Set |
| --- | --- |
| Send more model attributes | `'user' => ['attributes' => ['plan', 'team_name' => 'team.name']]` in `config/dimmi.php` |
| Build the identity yourself | `'user' => ['resolver' => App\Support\DimmiIdentity::class]`, an invokable class that returns the identity array |
| Let the messenger fetch tokens from the built-in `GET /dimmi/token` route | `DIMMI_MESSENGER_IDENTITY=url` |

## Call the API

The `Dimmi` facade forwards to the PHP SDK's client and throws its exceptions.

```php title="app/Listeners/SyncCustomer.php"
<?php

namespace App\Listeners;

use Dimmi\Laravel\Facades\Dimmi;
use Illuminate\Auth\Events\Registered;

class SyncCustomer
{
    public function handle(Registered $event): void
    {
        Dimmi::contacts()->store([
            'email' => $event->user->email,
            'external_id' => (string) $event->user->id,
        ]);
    }
}
```

## Receive webhooks

`Route::dimmiWebhooks('webhooks/dimmi')` in `routes/web.php` registers a route that checks each signature, answers `400` to an unsigned request, and fires two events:

- **`Dimmi\Laravel\Events\DimmiWebhookReceived`** for each webhook, with the event in `$received->event`.
- **`dimmi.webhook.<type>`**, such as `dimmi.webhook.conversation.created`, with a `Dimmi\WebhookEvent`.

[Verify webhook signatures](/developers/webhooks/verify-signatures/) has a listener to paste.
