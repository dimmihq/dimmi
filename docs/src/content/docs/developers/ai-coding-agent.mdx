The [`dimmi-install` skill](https://github.com/dimmihq/dimmi/tree/main/sdk/skills/dimmi-install) teaches AI coding agents how to add the dimmi messenger and identity verification to your codebase.

## Add the skill to Claude Code

Run this from your project root:

```bash
mkdir -p .claude/skills/dimmi-install
curl -fsSL https://raw.githubusercontent.com/dimmihq/dimmi/main/sdk/skills/dimmi-install/SKILL.md \
  -o .claude/skills/dimmi-install/SKILL.md
```

## Add the rules to Cursor, Codex, and other agents

Append the compact rules to your `AGENTS.md`:

```bash
curl -fsSL https://raw.githubusercontent.com/dimmihq/dimmi/main/sdk/skills/dimmi-install/AGENTS.snippet.md >> AGENTS.md
```

## Prompt your agent

```text
Install the dimmi messenger in this app with the dimmi-install skill.
App ID: <app_id>. Host: https://trydimmi.com.
Verify signed-in users with identity tokens.
```

Copy `<app_id>` (`wgt_...`) from **Settings → Messengers**. Always add your identity secret to your server environment yourself rather than pasting it into agent chat.
