Every event type a webhook endpoint can subscribe to, plus the JSON envelope sent on each delivery. You can fetch the same list via [List webhook event types](/api-reference/webhooks/list-webhook-event-types/).

## Event envelope

| Field | Type | Description |
| --- | --- | --- |
| `id` | string | Unique event ID (`evt_...`), repeated on retries and in `webhook-id`. |
| `object` | string | Always `event`. |
| `type` | string | Event name, such as `conversation.created`. |
| `api_version` | string | Payload version (`2026-11-01`). |
| `created_at` | string (date-time) | UTC timestamp of the event. |
| `workspace_id` | string | Workspace ID (`ws_...`). |
| `sequence` | integer | Monotonic per-object version (`0` on test events). Higher numbers are newer. |
| `test` | boolean | `true` for test deliveries with sample data. |
| `truncated` | boolean | `true` when the payload exceeds 256 KiB and `data.object` is reduced to a reference. See [Webhook delivery and retries](/developers/webhooks/delivery-and-retries/). |
| `actor.type` | string | `member` (teammate), `contact` (customer), `agent` (dimmi agent), `system`, or `integration`. |
| `actor.id` | string or null | Teammate ID (`mem_...`) or customer ID (`ctc_...`), or `null` for system/agent/integration. |
| `data.object` | object | Primary resource for the event. |
| `data.*` | varies | Extra event-specific fields listed under "Also in `data`" below. |

## Shapes of `data.object`

`data.object` matches the REST API response format. Deleted objects send `{"id": "...", "object": "<kind>", "deleted": true}`.

| `object` | Matches REST API endpoint |
| --- | --- |
| `conversation` | [Get conversation](/api-reference/conversations/get-conversation/), plus `deleted_at`. |
| `message` | Item from [List conversation messages](/api-reference/conversations/list-conversation-messages/). |
| `contact` | [Get contact](/api-reference/contacts-and-companies/get-contact/). |
| `tag` | Item from [List tags](/api-reference/conversations/list-tags/). |
| `changelog_entry` | [Get changelog entry](/api-reference/feedback-and-changelog/get-changelog-entry/). |
| `feedback_post` | [Get feedback post](/api-reference/feedback-and-changelog/get-feedback-post/). |
| `broadcast` | [Get broadcast](/api-reference/broadcasts-and-series/get-broadcast/). |
| `series` | [Get series](/api-reference/broadcasts-and-series/get-series/). |
| `ticket` | [Get ticket](/api-reference/tickets/get-ticket/). |
| `series_enrollment` | One customer's journey through a series. |
| `contact_event` | `id`, `object`, `contact`, `occurred_at`, `name`, and `ref`. |

## Conversations

Each `changes` entry is an object with `from` and `to`.

| Event | Fires when | Also in `data` |
| --- | --- | --- |
| `conversation.created` | A conversation starts. | |
| `conversation.updated` | Subject or inbox changes. | `changes` |
| `conversation.assigned` | Assignee or team changes. | `changes`, `reason` |
| `conversation.closed` | A conversation closes. | `reason` |
| `conversation.rated` | A customer submits or edits a rating. | `rating` |
| `conversation.reopened` | A closed conversation reopens. | `reason` |
| `conversation.snoozed` | A conversation is snoozed. | `snoozed_until` |
| `conversation.unsnoozed` | A snooze ends. | `reason` |
| `conversation.priority_changed` | Priority changes. | `changes` |
| `conversation.tagged` | Tags are added. | `tag_ids` |
| `conversation.untagged` | Tags are removed. | `tag_ids` |
| `conversation.marked_spam` | Marked as spam. | |
| `conversation.unmarked_spam` | Removed from spam. | |
| `conversation.merged` | Another conversation merges into this one. | `merged_id` |
| `conversation.participants_changed` | Participants are added or removed. | `added`, `removed` |
| `conversation.deleted` | Moved to trash. | |

## Messages

Note events (including `ticket.note_created`) only deliver to endpoints with **Internal notes** turned on.

| Event | Fires when | Also in `data` |
| --- | --- | --- |
| `message.created` | A message or note is added. | |
| `message.updated` | A note is edited. | |
| `message.deleted` | A message or note is deleted. | |
| `message.delivery_updated` | Delivery status changes (delivered, read, or failed). | `delivery_status`, `delivery_error` |

## Contacts

Wildcards exclude `contact_event.tracked` (whose `data.object` is a `contact_event`). Subscribe to it by name.

| Event | Fires when | Also in `data` |
| --- | --- | --- |
| `contact.created` | A contact is created. | |
| `contact.updated` | Contact fields or attributes change. | `changes`, `changed_attributes` |
| `contact.deleted` | A contact is erased. | |
| `contact.merged` | Another contact merges into this one. | `merged_id`, `moved` |
| `contact_event.tracked` | An event is tracked for a contact. | `name`, `ref` |

| `tag.created` | A tag is created. |

| Event | Fires when | Also in `data` |

## Changelog

| Event | Fires when |
| --- | --- |
| `changelog_entry.published` | A changelog entry publishes. |
| `changelog_entry.updated` | A live changelog entry republishes with edits. |
| `changelog_entry.unpublished` | A changelog entry returns to draft. |

## Feature requests

| Event | Fires when | Also in `data` |
| --- | --- | --- |
| `feedback_post.created` | A feature request is posted. | |
| `feedback_post.status_changed` | Status changes. | `changes` |
| `feedback_post.voted` | A customer votes on a request. | `vote` |
| `feedback_post.merged` | A duplicate request merges into this one. | `merged_id` |

| --- | --- | --- |

## Series

| Event | Fires when | Also in `data` |
| --- | --- | --- |
| `series.published` | A new series version goes live. | `version_id` |

## Tickets

Every ticket event also includes `kind` and `changes` inside `data`.

| Event | Fires when |
| --- | --- |
| `ticket.created` | A ticket is created or converted from a conversation. |
| `ticket.updated` | Title, description, or custom fields change. |
| `ticket.state_changed` | Ticket state changes. |
| `ticket.resolved` | Ticket enters a resolved state. |
| `ticket.reopened` | A resolved ticket reopens. |
| `ticket.assigned` | Teammate or team assignment changes. |
| `ticket.type_changed` | Ticket type changes. |
| `ticket.linked` | Linked to another ticket or conversation. |
| `ticket.unlinked` | A ticket link is removed. |
| `ticket.issue_linked` | Linked to a Linear, Jira, or GitHub issue, or an engineering incident. |
| `ticket.issue_updated` | A linked issue's status changes. |
| `ticket.note_created` | A teammate adds an internal note on a ticket. |
| `ticket.sla_warning` | An SLA target is about to breach. |
| `ticket.sla_breached` | An SLA target breaches. |
| `ticket.deleted` | Moved to trash. |
| `ticket.restored` | Restored from trash. |
