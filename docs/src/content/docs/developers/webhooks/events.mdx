The event types a webhook endpoint can receive, and the envelope each delivery carries. [List webhook event types](/api-reference/webhooks/list-webhook-event-types/) returns the same list.

## Envelope

| Field | Type | Description |
| --- | --- | --- |
| `id` | string | The event's ID (`evt_...`). The same on each attempt and endpoint, and in the `webhook-id` header. |
| `object` | string | `event`. |
| `type` | string | The event type, such as `conversation.created`. |
| `api_version` | string | The payload version, `2026-11-01`. |
| `created_at` | string (date-time) | The time of the event, in UTC. |
| `workspace_id` | string | The workspace's ID (`ws_...`). |
| `sequence` | integer | For one object, a higher `sequence` carries a newer snapshot. `0` on test sends. |
| `test` | boolean | `true` on a test send, with a sample in `data.object`. |
| `truncated` | boolean | `true` for an envelope over 256 KiB, with a reference in `data.object`. See [Webhook delivery and retries](/developers/webhooks/delivery-and-retries/). |
| `actor.type` | string | `member` (a teammate), `contact` (a customer), `agent` (the dimmi agent), `system` or `integration`. |
| `actor.id` | string or null | The teammate's ID (`mem_...`) or the customer's ID (`ctc_...`). `null` for the other types. |
| `data.object` | object | The object the event is about. |
| `data.*` | | The event's other fields, in the "Also in `data`" column below. |

## The object in data.object

`data.object` has the shape the REST API returns. For an object that no longer exists, it is `{"id": "...", "object": "<kind>", "deleted": true}`.

| `object` | Same shape as |
| --- | --- |
| `conversation` | [Get conversation](/api-reference/conversations/get-conversation/), plus `deleted_at`. |
| `message` | An entry of [List conversation messages](/api-reference/conversations/list-conversation-messages/). |
| `contact` | [Get contact](/api-reference/contacts-and-companies/get-contact/). |
| `tag` | An entry of [List tags](/api-reference/conversations/list-tags/). |
| `changelog_entry` | [Get changelog entry](/api-reference/feedback-and-changelog/get-changelog-entry/). |
| `feedback_post` | [Get feedback post](/api-reference/feedback-and-changelog/get-feedback-post/). |
| `broadcast` | [Get broadcast](/api-reference/broadcasts-and-series/get-broadcast/). |
| `series` | [Get series](/api-reference/broadcasts-and-series/get-series/). |
| `ticket` | [Get ticket](/api-reference/tickets/get-ticket/). |
| `series_enrollment` | One person's journey through a series. |
| `contact_event` | `id`, `object`, `contact`, `occurred_at`, `name` and `ref`. |

## Conversations

A `changes` entry is an object with `from` and `to`.

| Event | Fires when | Also in `data` |
| --- | --- | --- |
| `conversation.created` | A conversation started. | |
| `conversation.updated` | A conversation's subject or inbox changed. | `changes` |
| `conversation.assigned` | A conversation's assignee or team changed. | `changes`, `reason` |
| `conversation.closed` | A conversation was closed. | `reason` |
| `conversation.rated` | A customer rated a closed conversation or changed their rating. | `rating` |
| `conversation.reopened` | A closed conversation opened again. | `reason` |
| `conversation.snoozed` | A conversation was snoozed. | `snoozed_until` |
| `conversation.unsnoozed` | A snooze ended. | `reason` |
| `conversation.priority_changed` | A conversation's priority changed. | `changes` |
| `conversation.tagged` | Tags were added to a conversation. | `tag_ids` |
| `conversation.untagged` | Tags were removed from a conversation. | `tag_ids` |
| `conversation.marked_spam` | A conversation was marked as spam. | |
| `conversation.unmarked_spam` | A conversation was taken out of spam. | |
| `conversation.merged` | Another conversation was merged into this one. | `merged_id` |
| `conversation.participants_changed` | People were added to or removed from a conversation. | `added`, `removed` |
| `conversation.deleted` | A conversation moved to the trash. | |

## Messages

dimmi sends note events, including `ticket.note_created`, only to endpoints with **Internal notes** turned on.

| Event | Fires when | Also in `data` |
| --- | --- | --- |
| `message.created` | A message or note was added to a conversation. | |
| `message.updated` | A note was edited. | |
| `message.deleted` | A message or note was deleted. | |
| `message.delivery_updated` | A sent message was delivered, read or failed. | `delivery_status`, `delivery_error` |

## Contacts

Wildcards leave out `contact_event.tracked`, whose `data.object` is a `contact_event`; list it by name.

| Event | Fires when | Also in `data` |
| --- | --- | --- |
| `contact.created` | A contact was added. | |
| `contact.updated` | A contact's details changed. | `changes`, `changed_attributes` |
| `contact.deleted` | A contact was erased. | |
| `contact.merged` | Another contact was merged into this one. | `merged_id`, `moved` |
| `contact_event.tracked` | Your app tracked an event for a contact. | `name`, `ref` |

## Series

| Event | Fires when | Also in `data` |

## Tickets

Each ticket event also carries `kind`, the ticket's kind, and `changes` in `data`.

| Event | Fires when |
| --- | --- |
| `ticket.created` | A ticket was created or a conversation converted. |
| `ticket.updated` | A ticket's title, description or field values changed. |
| `ticket.state_changed` | A ticket moved to another state. |
| `ticket.resolved` | A ticket entered a resolved state. |
| `ticket.reopened` | A resolved ticket left the resolved states. |
| `ticket.assigned` | A ticket's teammate or team changed. |
| `ticket.type_changed` | A ticket moved to another type. |
| `ticket.linked` | A ticket was linked to another ticket or a conversation. |
| `ticket.unlinked` | A ticket link was removed. |
| `ticket.issue_linked` | A Linear, Jira or GitHub issue or an engineering incident was linked. |
| `ticket.issue_updated` | A linked issue's status changed. |
| `ticket.note_created` | A teammate left an internal note on a ticket. |
| `ticket.sla_warning` | A ticket's service level target is about to be missed. |
| `ticket.sla_breached` | A ticket missed a service level target. |
| `ticket.deleted` | A ticket moved to the trash. |
| `ticket.restored` | A ticket came back from the trash. |
