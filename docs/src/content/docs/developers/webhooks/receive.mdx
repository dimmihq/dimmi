---
title: "Receive webhooks"
description: "Create a webhook endpoint, subscribe to dimmi events, verify signatures, and process deliveries idempotently."
---

Add a webhook endpoint in **Settings → Webhooks**, or via [Create webhook endpoint](/api-reference/webhooks/create-webhook-endpoint/). Each workspace supports up to 20 endpoints, and dimmi Cloud requires `https://` URLs.

## Subscribe to events

| Pattern | Events delivered |
| --- | --- |
| `conversation.created` | Only that event. |
| `conversation.*` | Every event in that group, including future additions. |
| `*` | Every event type, including future additions. |

Wildcards exclude `contact_event.tracked`. List `contact_event.tracked` explicitly if you want it.

## Event envelope

Every delivery is an HTTP `POST` with a JSON envelope:

```json
{
  "id": "evt_01jd8y3q8k6m2v9x4t7b5n1c0r",
  "object": "event",
  "type": "conversation.created",
  "api_version": "2026-11-01",
  "created_at": "2026-11-19T10:42:07Z",
  "workspace_id": "ws_01jd8xzp2g4h7k9m3q5s8v1w6y",
  "sequence": 48213,
  "test": false,
  "truncated": false,
  "actor": { "type": "contact", "id": "ctc_01jd8y2r6t9w3z5b8d1f4h7k0m" },
  "data": {
    "object": { "id": "conv_01jd8y3q7j5k1n8p2r6t9v3x0z", "object": "conversation" }
  }
}
```

| Field | What it tells you |
| --- | --- |
| `id` | Stable event ID, repeated on retries and in the `webhook-id` header. |
| `sequence` | Increasing version number per object so you can ignore stale snapshots. |
| `data.object` | Full REST API representation of the object (trimmed in the sample above). |

See [Webhook events](/developers/webhooks/events/) for every envelope field and event type.

## Process each event once

Because webhooks can retry or arrive out of order, deduplicate by `id` and ignore any `sequence` lower than the latest one you already applied to that object:

```js title="server.js"
import express from "express";
import { Webhook } from "standardwebhooks";

const app = express();
const webhook = new Webhook(process.env.DIMMI_WEBHOOK_SECRET);

const seen = new Set(); // Use your database in production.
const latest = new Map(); // Object id -> highest sequence applied.

app.post("/webhooks/dimmi", express.raw({ type: "application/json" }), (req, res) => {
  let event;
  try {
    event = webhook.verify(req.body, req.headers);
  } catch {
    return res.status(400).end();
  }
  res.status(204).end();

  const object = event.data.object;
  if (seen.has(event.id) || (latest.get(object.id) ?? -1) >= event.sequence) {
    return;
  }
  seen.add(event.id);
  latest.set(object.id, event.sequence);

  console.log(event.type, object.id);
});

app.listen(3000);
```

Set `DIMMI_WEBHOOK_SECRET` to the endpoint's signing secret. Need Go, PHP, Laravel, or Python examples? See [Verify webhook signatures](/developers/webhooks/verify-signatures/).

Return any `2xx` status within 15 seconds and push slow work to a background job. See [Webhook delivery and retries](/developers/webhooks/delivery-and-retries/) for retry timing and failure handling.
