Control the messenger from JavaScript using the global `Dimmi(command, ...args)` function or the `@dimmi/browser` client returned by every `@dimmi` framework package.

## Commands

| Command | Arguments | Client method | What it does |
| --- | --- | --- | --- |
| `open` | None | `show()` | Opens the messenger. |
| `close` | None | `hide()` | Closes the messenger. |
| `toggle` | None | `toggle()` | Toggles the messenger open or closed. |
| `ask` | `text` | `showNewMessage(text)` | Starts a new conversation with `text` as the first message. |
| `update`, `boot` | `settings` | `update(settings)` | Merges settings over the current config and redraws. |
| `identify` | `source` (optional) | `identify(source?)` | Sets the [identity token](/developers/messenger/identity-verification/) provider, or refreshes the current one if omitted. |
| `logout`, `shutdown` | None | `shutdown()` | Ends the customer's session in the browser and on the server. |
| `track` | `name`, `metadata` | `trackEvent(name, metadata?)` | Tracks a customer [event](/developers/messenger/track-events/). |

If you call `Dimmi()` before the loader script finishes loading, add this tiny queue stub first:

```html
<script>
  window.Dimmi =
    window.Dimmi ||
    function () {
      (Dimmi.q = Dimmi.q || []).push([].slice.call(arguments));
    };
</script>
```

## Runtime settings

Pass any of these keys to `update`. Omitted keys keep your dashboard defaults.

| Key | Value |
| --- | --- |
| `appearance.primary_color` | Hex color (such as `#0f766e`) |
| `appearance.header_color`, `appearance.button_color` | Hex color |
| `appearance.theme` | `"light"`, `"dark"`, or `"auto"` |
| `appearance.position` | `"right"` or `"left"` |
| `appearance.padding_x`, `appearance.padding_y` | Offset in pixels from the side and bottom edges |
| `appearance.launcher.style` | `"bubble"`, `"tab"`, or `"hidden"` |
| `appearance.launcher.shape` | `"circle"` or `"squircle"` |
| `appearance.launcher.label` | Custom tab label text |
| `appearance.font` | `"system"` or `"inherit"` (matches your page font) |
| `appearance.sound` | Boolean; `false` silences the messenger |
| `appearance.sent_sound`, `appearance.reply_sound` | `"none"`, `"pop"`, `"chime"`, `"bubble"`, `"swoosh"`, or `"tick"` |
| `texts` | Key-value overrides such as `greeting`, `chat_title`, or `composer_placeholder` |
| `language` | Language tag such as `fr` or `pt-BR` |

```js
Dimmi("update", {
  appearance: { primary_color: "#0f766e", launcher: { style: "tab", label: "Help" } },
});
```

## Script tag attributes

| Attribute | Value |
| --- | --- |
| `src` | `<host>/widget/v1/loader.js` |
| `data-app-id` | Messenger app ID (`wgt_...`) |
| `data-api-base` | Custom API origin if different from the loader host |
| `data-identity-url` | Same-origin endpoint returning the identity token |
| `nonce` | [Content Security Policy](/developers/messenger/content-security-policy/) nonce |

## HTML button triggers

Clicking any element with `data-dimmi="open"`, `"close"`, or `"toggle"` runs that command automatically.

## Window events

The messenger fires `dimmi:unread` on `window` on startup and whenever the unread count changes. Read the count from `event.detail.count`.

## @dimmi/browser functions and options

Every helper is SSR-safe and does nothing on the server.

| Function | What it does |
| --- | --- |
| `loadDimmi(options)` | Injects the loader script once and returns the client. |
| `getDimmi()` | Returns the client for a messenger loaded elsewhere (such as via script tag). |
| `dimmi(name, ...args)` | Sends a raw command (same as `client.command()`). |

`loadDimmi()`, `<DimmiProvider>`, `<Dimmi>`, `createDimmi()`, `provideDimmi()`, and `initDimmi()` share these options (`<Dimmi>` in `@dimmi/nextjs` accepts `appId`, `host`, `identity`, and `nonce`):

| Option | Value |
| --- | --- |
| `appId` | Required. Messenger app ID. |
| `host` | Required. `https://trydimmi.com`, or your self-hosted URL. |
| `apiBase` | Sets `data-api-base`. |
| `nonce` | Sets `nonce`. |
| `identity` | Function returning a JWT string or `null`. |
| `identityUrl` | Sets `data-identity-url`. |
| `settings` | Initial runtime settings. |

Along with every method in [Commands](#commands), the client exposes:

| Member | What it does |
| --- | --- |
| `ready` | Promise that resolves when the loader finishes and rejects if blocked. |
| `onUnreadCountChange(fn)` | Subscribes to `dimmi:unread` with `fn(count)` and returns an unsubscribe function. |
