---
title: "Authenticate API requests"
description: "Create a dimmi API token and send it as a Bearer token on REST API requests."
---

Create an API token in **Settings → API tokens** and send it in the `Authorization` header on every request:

```bash
curl https://trydimmi.com/api/v1/workspace \
  -H "Authorization: Bearer <api_token>"
```

Replace `<api_token>` with your token. If you self-host, call `/api/v1` on your own server URL instead.

- **One workspace per token:** each token only accesses the workspace active when you created it.
- **Required abilities:** every endpoint requires a specific ability, such as `conversations:read`. See [API token abilities](/developers/api/abilities/).
- **Follows your role:** dimmi checks your workspace role on every call, so a token can never exceed your current permissions.
- **Limits:** up to 50 active tokens per workspace and 20 new tokens per hour.

Use the same token with our [TypeScript](/developers/sdks/typescript/), [Go](/developers/sdks/go/), [PHP](/developers/sdks/php/), [Laravel](/developers/sdks/laravel/), and [Python](/developers/sdks/python/) SDKs.
