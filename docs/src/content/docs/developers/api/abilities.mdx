---
title: "API token abilities"
description: "See every ability an API token can hold and which REST API endpoints each ability opens."
---

Every endpoint in the [API reference](/api-reference/) lists the ability it requires. Calling an endpoint without that ability returns `403` with `code: "missing_ability"` and the missing scope in `required_ability`.

## Available abilities

You can only grant abilities that your own workspace role has permission to use.

| Ability | What it opens |
| --- | --- |
| `conversations:read` | Read conversations, messages, inboxes, tags, saved replies, conversation reports, and data exports. |
| `conversations:write` | Create and update conversations, send replies and notes, manage saved replies, create tags. |
| `contacts:read` | Read customers (`contact` in the API), companies, attribute/event definitions, and email suppressions. |
| `contacts:write` | Create, update, import, and erase customers and companies, and track customer events. |
| `attributes:write` | Manage attribute and event definitions. |
| `audiences:read` | Read audiences. |
| `audiences:write` | Create, update, and delete audiences. |
| `tickets:read` | Read tickets, events, types, states, and ticket reports. |
| `tickets:write` | Create and update tickets, tracker links, and linked issues. |
| `articles:read` | Read help centers, articles, and collections. |
| `articles:write` | Create and update articles and collections. |
| `changelog:read` | Read changelog entries, labels, and subscribers. |
| `changelog:write` | Create and update changelog entries, labels, and subscribers. |
| `feedback:read` | Read feature request boards, posts, and statuses. |
| `feedback:write` | Create and update feature request posts and comments. |
| `broadcasts:read` | Read broadcasts and topics. |
| `broadcasts:write` | Create and update broadcasts and topics. |
| `series:read` | Read series and enrollments. |
| `series:write` | Create and update series. |
| `workflows:read` | Read workflows and schedules. |
| `workflows:write` | Create and update workflows and schedules. |
| `ai:read` | Read dimmi agent settings, actions, runs, procedures, saved simulations, versions, procedure metrics, and procedure reports. |
| `ai:write` | Update dimmi agent settings and procedures, run preview turns and simulations, publish or pause procedures, and restore versions. |
| `ai:actions` | Create, update, and publish actions and connections. |
| `ai:keys` | Add, update, and remove AI provider keys. |
| `members:read` | Read members, invitations, teams, roles, and permissions. |
| `members:write` | Manage members, invitations, and teams. |
| `webhooks:read` | Read webhook endpoints, deliveries, and event types. |
| `webhooks:write` | Manage webhook endpoints and retry deliveries. |
| `exports:write` | Start an export of the whole workspace. Owners only, and the token also needs `conversations:read`. |
| `settings:read` | Read workspace settings: channels, email, messengers, integrations, knowledge sources, SLA policies, and audit log. |
| `settings:write` | Update those settings, plus inboxes, help centers, ticket types/states/fields, and feature request boards. |

Note: `notifications:read`, `notifications:write`, `exports:read`, `engage:read`, `engage:write`, `billing:read`, `billing:write`, `system:read`, and `system:write` are reserved and do not open public API endpoints.

## Endpoints without an ability

| Endpoints | Token behavior |
| --- | --- |
| `GET /me`, `GET /workspace`, `GET /workspace/entitlements` | Accessible with any valid API token. |
| Internal admin endpoints with no listed ability (such as SSO or custom role edits) | Not available to API tokens; return `403` with `code: "credential_not_accepted"`. |
