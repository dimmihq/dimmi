---
title: "Add AI provider keys"
description: "Configure server-wide Anthropic, OpenAI, and embedding keys so the dimmi agent and Operator work out of the box."
---

Setting AI keys at the server level gives every workspace a built-in **dimmi** AI provider. Without them, each workspace brings its own keys in **Settings → AI providers** ([AI providers](/ai/providers/)).

```bash
dimmictl set <<'EOF'
DIMMI_AI__MANAGED__ANTHROPIC__API_KEY=<anthropic_api_key>
DIMMI_AI__MANAGED__OPENAI__API_KEY=<openai_api_key>
DIMMI_AI__MANAGED__EMBEDDINGS__API_KEY=<embeddings_api_key>
EOF
```

- **Chat models:** add Anthropic, OpenAI, or both. Workspaces see only models for providers whose keys you set.
- **Embeddings:** enables semantic search across knowledge sources. Without a server embedding key, semantic search only activates for workspaces with their own OpenAI key.

## Optional settings

Prefix each variable below with `DIMMI_AI__`:

| Variable | Default | Description |
| --- | --- | --- |
| `MANAGED__ANTHROPIC__BASE_URL` | Anthropic API | Custom endpoint or proxy URL for Anthropic calls. |
| `MANAGED__OPENAI__BASE_URL` | OpenAI API | Custom endpoint or proxy URL for OpenAI calls. |
| `MANAGED__EMBEDDINGS__BASE_URL` | `https://api.deepinfra.com/v1/openai` | OpenAI-compatible embeddings API URL. |
| `MANAGED__EMBEDDINGS__MODEL` | `Qwen/Qwen3-Embedding-8B` | Embedding model (must output 1024 dimensions). |
| `DEFAULT_MONTHLY_CAP_USD` | `25` | Starting monthly AI spend cap (USD) for new workspaces. |
| `ENABLED` | `true` | Set `false` to disable the dimmi agent server-wide. |

Diagnose anything blocking the agent from replying with:

```bash
docker compose -f /opt/dimmi/compose.yaml exec web /dimmi ai:doctor
```
