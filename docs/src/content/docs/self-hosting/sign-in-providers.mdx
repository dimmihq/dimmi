---
title: "Enable Google and GitHub sign-in"
description: "Add Google or GitHub OAuth sign-in buttons to your self-hosted dimmi login screen."
---

Once you set a provider's client ID and secret, dimmi shows its sign-in button automatically on the login page.

Create an OAuth app with the matching callback URL (`<app_domain>` is your dimmi hostname):

| Provider | Where to register | Callback URL |
| --- | --- | --- |
| **Google** | Google Cloud Console → **APIs & Services → Credentials** → Web application OAuth client | `https://<app_domain>/auth/google/callback` |
| **GitHub** | **Settings → Developer settings → OAuth Apps** | `https://<app_domain>/auth/github/callback` |

Save the credentials for whichever provider(s) you want:

```bash
dimmictl set <<'EOF'
DIMMI_AUTH__OAUTH__GOOGLE__CLIENT_ID=<google_client_id>
DIMMI_AUTH__OAUTH__GOOGLE__CLIENT_SECRET=<google_client_secret>
DIMMI_AUTH__OAUTH__GITHUB__CLIENT_ID=<github_client_id>
DIMMI_AUTH__OAUTH__GITHUB__CLIENT_SECRET=<github_client_secret>
EOF
```

New users still need an invitation unless you set `DIMMI_AUTH__SIGNUP__MODE=open`.

Need corporate SAML or OIDC login? Each workspace configures [single sign-on](/workspace/single-sign-on/) on its own in Settings.
