---
title: "Enable Google and GitHub sign-in"
description: "Let teammates sign in to your self-hosted dimmi with Google or GitHub."
---

dimmi shows a Google or GitHub button on the sign-in page once that provider's client ID is set.

Create an OAuth app at the provider with this callback URL:

| Provider | Where to create the app | Callback URL |
| --- | --- | --- |
| Google | Google Cloud console, **APIs & Services → Credentials**, an OAuth client of type Web application | `https://<app_domain>/auth/google/callback` |
| GitHub | **Settings → Developer settings → OAuth Apps** | `https://<app_domain>/auth/github/callback` |

Then give dimmi the app's client ID and secret:

```bash
dimmictl set <<'EOF'
DIMMI_AUTH__OAUTH__GOOGLE__CLIENT_ID=<google_client_id>
DIMMI_AUTH__OAUTH__GOOGLE__CLIENT_SECRET=<google_client_secret>
DIMMI_AUTH__OAUTH__GITHUB__CLIENT_ID=<github_client_id>
DIMMI_AUTH__OAUTH__GITHUB__CLIENT_SECRET=<github_client_secret>
EOF
```

`<app_domain>` is the domain you installed dimmi on. Set only the provider you want.

A person who has no dimmi account still needs an invitation to sign in this way, unless `DIMMI_AUTH__SIGNUP__MODE` is `open`.

For SAML or OIDC through a company's identity provider, each workspace sets up [single sign-on](/workspace/single-sign-on/) itself.
