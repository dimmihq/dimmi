A self-hosted dimmi runs as a single Docker Compose stack on one Linux server, managed with the `dimmictl` CLI.

## Server requirements

| Requirement | Minimum |
| --- | --- |
| **Operating system** | Ubuntu 22.04 or 24.04, or Debian 12 |
| **CPU** | 2 vCPU |
| **Memory** | 4 GB (6 GB if you turn on ClamAV malware scanning) |
| **Disk** | 40 GB |
| **Network** | Public IPv4 address with ports 80 and 443 open |
| **Access** | `root`, or a user with `sudo` |

Using another Linux distribution? Install Docker with the Compose plugin yourself and pass `--skip-prepare` to the [installer](/self-hosting/install/).

## Domain setup

Point one hostname (such as `support.example.com`) at your server's public IPv4 address with an `A` record. That single host serves the dashboard, REST API, uploads, help centers, and incoming webhooks.

Caddy requests Let's Encrypt certificates automatically, so traffic must reach your server without a reverse proxy in front. If you use Cloudflare DNS, set the record to **DNS only**.

## Services in the stack

Every service talks over a private Docker network, except `caddy`, which handles public HTTP and HTTPS traffic.

| Service | Image | Role |
| --- | --- | --- |
| `caddy` | `caddy:2.10` | Only public service. Listens on ports 80 and 443, manages TLS, and proxies to `web`. |
| `web` | `ghcr.io/dimmihq/dimmi` | Web dashboard and HTTP APIs. |
| `worker` | `ghcr.io/dimmihq/dimmi` | Background jobs and scheduled tasks. |
| `migrate` | `ghcr.io/dimmihq/dimmi` | Runs database migrations before `web` and `worker` boot, then exits. |
| `postgres` | `pgvector/pgvector:pg18` | Primary database, job queue, and sessions. |
| `valkey` | `valkey/valkey:8` | Cache, rate limits, and realtime pub/sub. |
| `seaweedfs` | `chrislusf/seaweedfs:3.97` | S3-compatible storage for uploaded files (served through dimmi's own URL). |
| `clamav` | `clamav/clamav:1.4` | Optional malware scanner for uploads and email attachments (~1.5 GB RAM). |

## Important files and volumes

The stack installs to `/opt/dimmi`:

| Path or volume | Contents |
| --- | --- |
| `/opt/dimmi/.env` | Your configuration and generated secrets, including `DIMMI_APP__KEY`. See [How configuration works](/self-hosting/configuration/). |
| `/opt/dimmi/compose.yaml`, `Caddyfile` | Stack definitions (updated by [`dimmictl update`](/self-hosting/upgrade/)). |
| `/opt/dimmi/VERSION` | Currently installed release tag. |
| `dimmi_postgres`, `dimmi_seaweedfs` | Docker volumes holding your database and uploads. See [Back up and restore](/self-hosting/backups/). |
