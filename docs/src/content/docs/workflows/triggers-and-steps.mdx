Every trigger and step available in the workflow builder, grouped the same way you see them on screen.

## Triggers

Your trigger decides which **Messages** steps and AI handoffs you can use. Every trigger allows **Logic**, **Team**, **Tickets**, and the other **AI agents** steps.

### Start of conversation

| Trigger | Notes | Messages steps | Hand to an AI agent |
| --- | --- | --- | --- |
| **Customer sends their first message** | Runs once per conversation. | All | Yes |
| **Customer writes on a closed conversation** | Fires when a closed thread reopens. | All | Yes |

### During conversation

| Trigger | Notes | Messages steps | Hand to an AI agent |
| --- | --- | --- | --- |
| **Customer sends a message** | Fires on every customer message. | None | No |
| **AI attribute changes** | Fires when the AI sets or changes one of your [AI attributes](/ai/ai-attributes/). Conditions can read which one changed and its new value. | None | No |
| **Customer stops replying** | Fires 1 hour, 4 hours, 1 day, 2 days, or 7 days after a reply from a teammate, dimmi, or either, with no customer reply since. Open threads only. | All | Yes |

### Team

| Trigger | Notes | Messages steps | Hand to an AI agent |
| --- | --- | --- | --- |
| **Teammate sends a reply** | | None | No |
| **Teammate adds a note** | | None | No |
| **Assignment changes** | | None | No |
| **Conversation status changes** | Optionally limit to **Open**, **Snoozed**, or **Closed**. | None | No |
| **Customer waits for the team** | Fires 5 minutes, 15 minutes, 30 minutes, 1 hour, or 4 hours after a customer starts waiting with no reply. Once per wait. | **Send a message**, **Show reply time** | No |

### Tickets

Ticket triggers run on the ticket's conversation. Standalone tickets with no conversation do not start workflows.

| Trigger | Messages steps | Hand to an AI agent |
| --- | --- | --- |
| **Ticket is created** | **Send a message** | No |
| **Ticket state changes** | **Send a message** | No |
| **Ticket fields change** | None | No |
| **Customer replies on a ticket** | None | No |
| **Ticket is linked** | None | No |
| **Linked issue changes** | **Send a message** | No |
| **Ticket needs the loop closed** | **Send a message** | No |

### AI agents

| Trigger | Messages steps | Hand to an AI agent |
| --- | --- | --- |
| **AI agent hands over** | None | No |
| **AI agent resolves a conversation** | **Send a message** | No |
| **AI agent transfers to another agent** | None | No |

To act on one agent only, add a branch on **AI agent**. Under the transfer trigger you can also branch on **Transferred from** and **Transferred to**.

### Reusable

| Trigger | Notes | Messages steps | Hand to an AI agent |

## Steps

### Messages

| Step | What it does | Paths |
| --- | --- | --- |
| **Send a message** | Sends text with optional variables. | |
| **Send an article** | Sends a published, public help center article. Opens in place in the messenger; other channels receive a link. | |
| **Reply buttons** | Asks a question with 2 to 6 buttons and waits for the customer's choice. | One per button, **Typed an answer**, **No answer in time** |
| **Collect data** | Asks for email, name, or phone and saves it. Skips the prompt if dimmi already has that value. | **Invalid answer**, **No answer in time** |
| **Show reply time** | Replaces `{{reply_time}}` with an estimate from your last 14 days of replies (such as "in a few minutes" or "within an hour"). Outside office hours, says when you reopen. | |

### Logic

| Step | What it does | Paths |
| --- | --- | --- |
| **Branch** | Follows the first of up to 10 matching conditions. | One per condition, **Everyone else** |
| **Sort by topic** | Asks AI to read the conversation and pick one of 2 to 10 topics. | One per category, **None matched or AI unavailable** |
| **A/B split** | Sends each conversation down one of 2 to 4 variants by the shares you set, which add up to 100%. A conversation keeps its variant every time it reaches the step. Once you pick a winner, everyone goes down it. See [A/B test a path](/workflows/build-a-workflow/#ab-test-a-path). | One per variant |
| **Extract with AI** | Asks AI to read the conversation and save up to 10 typed values (text, number, date, yes or no, one of a list) to run variables or contact attributes. A value the AI isn't sure of takes its fallback. | **None matched or AI unavailable** (when turned on), for a value with no fallback |
| **Wait** | Pauses for 5 minutes to 7 days, or until office hours open. Can count only office hours. | |
| **Run a workflow** | Runs a live reusable workflow and waits for it to finish. | |

### AI agents

| Step | What it does | Paths |
| --- | --- | --- |
| **Hand to an AI agent** | Hands the thread to the agent you pick, or to the agent placed on the channel. The agent answers with its own guidance and procedures. A named agent transfers only when you turn on **May transfer**. Hands over right away if the agent is off. A customer counts as quiet after 10 minutes in the messenger or 1 day on email unless you set another time. | **Resolved**, **Handed over**, **Customer went quiet** |
| **Assign an AI agent** | Puts the agent you pick on the conversation. It answers from the customer's next message. | |
| **Turn off AI** | Keeps every AI agent off the conversation until a teammate or a **Turn on AI** step lets one back in. A later **Hand to an AI agent** step still works. | |
| **Turn on AI** | Lets the agent answer again, even after a handover to the team. | |

### Team

| Step | What it does | Paths |
| --- | --- | --- |
| **Assign** | Assigns to a team, to teammates in turn, to the teammate with the fewest threads, or to one teammate. Leaves threads that are already assigned alone unless you change that setting. | |
| **Unassign** | Removes the teammate, the team, or both. | |
| **Tag** | Adds tags. | |
| **Remove tags** | Removes tags. | |
| **Set priority** | Sets none, low, medium, high, or urgent. | |
| **Add a note** | Adds an internal note with optional variables. | |
| **Update contact** | Sets the customer's name or phone number. | |
| **Snooze** | Snoozes for 5 minutes to 7 days, or until office hours open. | |
| **Close** | Closes the conversation. Can skip threads a teammate replied to, and can ask for a rating. | |
| **Apply an SLA** | Applies an SLA policy to the conversation (and its ticket, if it has one). | |
| **Run an action** | Calls one of your published [actions](/ai/actions/), the same ones your agents use, with inputs picked from contact details, AI attributes or run variables. Saves the outputs you pick. Runs without customer confirmation or teammate approval, since your team set it up. | **Failed** (when turned on) |

### Tickets

| Step | What it does |
| --- | --- |
| **Create a ticket** | Turns the conversation into a ticket of the type you choose. |
| **Set ticket state** | Moves the ticket to a new state. |
| **Set ticket fields** | Updates fields on the ticket. |
| **Escalate to a team** | Creates back-office work for another team. The ticket waits on that team until the work is done. |
| **Add to a tracker** | Links the conversation to a [tracker](/tickets/trackers/). |
