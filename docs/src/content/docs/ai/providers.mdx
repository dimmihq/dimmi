title: "Choose an AI provider and spending cap"
description: "Connect your own AI provider keys or use dimmi's built-in provider, and how the monthly spending cap works."
---

Admins add provider connections in **Settings → AI providers**. Once connected, pick a model for each agent in [Agent Studio](/ai/set-up-the-agent/), under **Build → Model → Answers with**. An agent left on **Workspace default** answers with the workspace's model.

[Operator](/operator/work-with-operator/) uses the same provider connections as your agents.

## Supported providers

You can add up to 20 connections per workspace.

| Provider | What you enter |
| --- | --- |
| **dimmi** | Nothing. It works out of the box on dimmi cloud. On a self-hosted server, it appears after you add [AI provider keys](/self-hosting/ai-providers/). |
| **Anthropic** | Your Anthropic API key. |
| **OpenAI** | Your OpenAI API key. |
| **Baseten** | Your Baseten API key. |
| **OpenAI-compatible** | The base URL of any server with OpenAI-style `/v1` endpoints, such as Ollama, vLLM, or LiteLLM. The API key is optional. |
| **ChatGPT subscription** | Sign in with your ChatGPT plan. Shown only where the server allows it. |

When you bring your own API key, your AI provider bills you at its normal rates. If your connection ever stops working, the agent [hands over](/ai/handover/) active conversations and stays quiet on new ones until you fix it.

## Set the monthly cap

The cap is the most your workspace spends on dimmi in a month. Every agent and Operator share it. New workspaces start at $25, and the lowest cap is $1.

- **How to change it:** send `monthly_cap_usd` to `PATCH /api/v1/ai/settings`. `0` or `null` removes the cap.
- **When it resets:** on the first of each calendar month in UTC.
- **When you hit the cap:** every agent hands over active conversations and stays quiet on new ones. Operator stops answering until the next month.
- **How to resume early:** raise the cap above your current month's spend, or remove it. Your agents and Operator start again right away.
