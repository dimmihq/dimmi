---
title: "Choose an AI provider and spending cap"
description: "Which AI providers the dimmi agent can answer through, how to use your own keys and how the monthly cap counts and stops spend."
---

Admins add provider connections in **Settings → AI providers**, then pick the connection and model in **Settings → dimmi agent**, under **Model**. [Operator](/operator/work-with-operator/) answers through the same connection.

## Providers

| Provider | What you give |
| --- | --- |
| **dimmi** | Nothing: it is built in. On a self-hosted server it appears once the server has [AI provider keys](/self-hosting/ai-providers/). |
| **Anthropic** | An API key. |
| **OpenAI** | An API key. |
| **Baseten** | An API key. |
| **OpenAI-compatible** | The base URL of a server with OpenAI-style `/v1` endpoints, such as Ollama, vLLM or LiteLLM. The API key is optional. |
| **ChatGPT subscription** | A sign-in with your ChatGPT plan. Offered only where the server allows it. |

- A workspace holds up to 20 connections.
- With your own key, the provider bills you at its prices.
- When the agent's connection stops working, the agent [hands over](/ai/handover/) the conversations it was answering and stays quiet in new ones.

## Set the monthly cap

Set **Monthly cap** in **Settings → dimmi agent**, under **Spend**. A new workspace starts at $25; the lowest cap is $1.

- **What counts:** the dimmi agent's replies and Operator's runs, on every connection. dimmi prices each one from its own list of model prices, in US dollars. A model with no price on that list counts as $0.
- **The month:** a calendar month in UTC.
- **At the cap:** the agent hands over the conversations it was answering and stays quiet in new ones. Operator stops answering. Both start again on the first of the next month.
- **During a capped month:** raising the cap above the month's spend, or switching to **No cap**, restarts them.
