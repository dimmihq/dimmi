Every template gets the variables under **Every page**, and its own under **Each page**. Partials see the same
globals, plus the arguments passed to `{% render %}`. Links are full paths under the help center's base, and
words are already in the page's language.

Print a variable with `{{ article.title }}`. Text is escaped for HTML; values marked HTML print as markup.

## Every page

| Variable | Type | What it holds |
| --- | --- | --- |
| `help_center` | [Center](#center) | The help center the page belongs to. |
| `reader` | [Person](#person) | The signed-in reader of the sample help center, nil otherwise. |
| `locale` | [Locale](#locale) | The page's language and the others it is in. |
| `page` | [Page](#page) | What the page says about itself. |
| `settings` | map | The theme's settings by id: the team's values, else the defaults in theme.json. |
| `translations` | map | Every word of the help center in the page's language, by key. |
| `platform_assets` | HTML | dimmi's stylesheet and script and the theme switch. Keep it to keep the default look. |
| `seo_tags` | HTML | Description, preview, robots, canonical, hreflang, Markdown and feed tags. |
| `messenger_snippet` | HTML | The script that loads the help center's messenger, empty when it shows none. |
| `form_token` | text | The anti-forgery token every form that posts must send as _token. |
| `form_token_field` | HTML | The hidden field holding form_token. |
| `script_nonce` | text | The nonce an inline script needs on the help center's own domain, empty elsewhere. |
| `content_for_layout` | HTML | In layouts only: the page's own output. |

| `icon` | text | Its icon. |
| `description` | text | What it is for. |
| `url` | text | Its form. |

### Ticket

Ticket is a reader's request, in a list or on its page.

| Field | Type | What it holds |
| --- | --- | --- |
| `ref` | text | Its reference, such as T-12. |
| `title` | text | Its subject. |
| `type` | text | Its type's name. |
| `type_icon` | text | Its type's icon. |
| `label` | text | Where it stands, as customers read it. |
| `group` | text | Submitted, in_progress, waiting_customer or resolved. |
| `updated` | text | When it last changed, such as 2h. |
| `mine` | true or false | The reader opened it, rather than someone at their company. |
| `url` | text | Its page. |
| `description` | text | On its page: its details. |
| `steps` | list of [RequestStep](#requeststep) | On its page: Submitted, We're on it and Resolved, with done and current. |
| `fields` | list of [RequestField](#requestfield) | On its page: the fields the reader sees, with label and value. |
| `messages` | list of [Message](#message) | On its page: the thread. |
| `error` | text | On its page: why a reply was refused. |
| `reply_url` | text | On its page: where the reply form posts, with body. |

### Tickets

Tickets is tickets, on the reader's list of requests.

| Field | Type | What it holds |
| --- | --- | --- |
| `scope` | text | Company when the company's are shown, else empty. |
| `company` | true or false | The company tab shows. |
| `tabs` | list of [Link](#link) | My requests and Company requests. |
| `items` | list of [Ticket](#ticket) | The requests. |
| `types` | list of [TicketType](#tickettype) | The types the reader may open. |
| `new_url` | text | The form to open one. |

### Update

| `url` | text | Its address. |
| `label` | text | Its first label, empty for none. |
| `published` | time | When it was published. |

### Week

Week is a week of the release strip.

| Field | Type | What it holds |
| --- | --- | --- |
| `month_name` | text | The month it opens, when it is the first week of one, else empty. |
| `title` | text | The entry published in it, empty for none. |
| `url` | text | That entry's page, empty for none. |
