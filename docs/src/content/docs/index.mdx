dimmi puts every support channel in one shared inbox so your whole team can help customers without paying per seat. Turn on the **dimmi agent** to answer common questions from your docs, or use **Operator** behind the scenes to brief teammates and draft replies.

Both [dimmi Cloud and self-hosted installs](/cloud-vs-self-hosted/) run the exact same MIT code with every feature included.
