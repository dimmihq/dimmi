---
title: "Audit log"
description: "Track who changed what in your workspace, see every logged event, and export filtered CSV reports."
---

Open **Settings → Audit log** to see a record of security and configuration changes across your workspace. Owners and Admins can view it (`audit_logs:read`).

## What each entry records

| Column | Details |
| --- | --- |
| **Event** | What happened (full list below). |
| **Actor** | The teammate, API token, or connected app behind the change, along with access method and IP address. System actions appear as **Automatic**. |
| **Target** | The item that changed. |
| **Time** | Exact timestamp. |

## Retention and CSV exports

| Setting | Behavior |
| --- | --- |
| **dimmi Cloud retention** | 365 days. Older entries purge daily. |
| **Self-hosted retention** | Kept forever unless you set a [retention limit](/self-hosting/configuration-options/#retention). |
| **Export CSV** | Downloads filtered entries for up to 366 days (defaults to last 30 days). |
| **Export rate limit** | Up to 10 exports per hour per workspace. |
| **Export logging** | Every CSV download logs its own **Exported the audit log** event. |
