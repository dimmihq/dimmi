---
title: "Roles and permissions"
description: "The permissions each built-in dimmi role holds, and the rules a custom role follows."
---

A workspace has three built-in roles, and each holds everything the role before it holds: Member (37 permissions), Admin (100) and Owner (111).

An [API token](/developers/api/abilities/) never does more than the role of the member who created it.

## Custom roles

A custom role holds part of what Member or Admin holds. Create one in **Settings → Roles**.

| Rule | Detail |
| --- | --- |
| Base role | Member or Admin, chosen when you create the role. It cannot change later. |
| Always held | `members:read`. |
| Out of reach | Owner permissions. |
| Your own limit | You grant only permissions you hold, and you edit only roles that hold nothing you lack. |
| Limit | 50 custom roles in a workspace, each with a unique name. |
| Editing | A change applies to every holder on their next request. |
| Assigning | An Owner never holds a custom role, and you cannot change your own. |
| Deleting | Only when nobody holds the role. |

The **New role** menu offers three starting points:

| Preset | Base role | Holds |
| --- | --- | --- |
| **Support agent** | Member | Conversations, contacts, reading articles, notifications, own signature and AI features. |
| **Read only** | Member | Every Member permission whose key ends in `:read`. |
| **Billing admin** | Admin | `billing:read`, `billing:write`, `settings:read` and `members:read`. |

## Owner permissions

An Owner holds the Member and Admin permissions and these. A workspace always keeps at least one active Owner.

| Permission | Key |
| --- | --- |
| Lift spending caps | `billing:cap_unrestricted` |
| Resume sending | `email:resume_sending` |
| Rotate signing keys | `email:rotate_dkim` |
| Lift complaint blocks | `email_suppressions:lift_complaint` |
| Download exports | `exports:read` |
| Start exports | `exports:write` |
| Delete help centers | `help_centers:delete` |
| Manage owners | `members:manage_owners` |
| Manage directory sync | `scim:manage` |
| Manage single sign-on | `sso:manage` |
| Delete the workspace | `workspace:delete` |
