---
title: "Connect Slack"
description: "What connecting Slack to dimmi does: which Slack messages open conversations, how the dimmi agent answers and what teammates' replies in Slack do."
---

Connect Slack in **Settings → Integrations**. Each Slack thread that needs an answer becomes a conversation in your default inbox, and replies flow both ways.

- dimmi connects one Slack workspace and watches only the channels you invite its app to.
- Each watched channel has its own [room mode](/channels/slack-room-modes/), trigger and agent settings.

## Triggers

A channel's trigger decides which top-level customer messages open a conversation.

| Trigger | Opens a conversation for |
| --- | --- |
| **Each new question** | A customer's message. Their next messages within 2 minutes join it while nobody has answered. The default. |
| **Every message**, **Every post** | Each message. |
| **Requests the AI spots** | Messages the AI reads as requests. |
| **When someone reacts** | A message anyone reacts to with `:ticket:`. |
| **When the app is mentioned** | A message that mentions the app. |
| **Never** | Nothing. |

With every trigger:

- Short thanks open no conversation. dimmi reads no messages from bots.
- A customer's reply in a thread continues that thread's conversation, or opens one. With **Never**, it only continues one.

## The dimmi agent in Slack

The dimmi agent answers in Slack when Slack is ticked under **Settings → dimmi agent → Where & when → Channels**. Each channel has a mode:

- **Answer in the thread:** the agent replies to the customer. The default.
- **Draft for review:** the agent posts a draft under the conversation's triage card for a teammate to send. Without a triage card, linked teammates see the draft as a private note in the channel.

The agent can wait up to 900 seconds before it answers. It steps back when a teammate replies in the thread or the customer mentions a teammate.

Under each agent answer, only the customer who asked can select **Solved**, which closes the conversation.

## Teammates in Slack

dimmi links a Slack user to a teammate when their Slack email is the verified sign-in email of an active workspace member.

- **Reply in a customer's thread:** dimmi records a linked teammate's reply as their answer.
- **Write under a triage card:** the message becomes a note the customer does not see. Start it with `>>` to reply to the customer. dimmi posts the cards in the channel set under **Post new conversations to**.
- **React to the customer's first message:** `:white_check_mark:` closes the conversation, `:eyes:` assigns it to you and `:rotating_light:` makes it urgent.
