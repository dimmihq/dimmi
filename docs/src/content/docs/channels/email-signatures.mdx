---
title: "Set email signatures and reply style"
description: "Choose Plain or Branded email replies, set personal and team signatures, and insert dynamic variables."
---

Set each address's reply style and team signature in **Settings → Email**. Teammates set their personal signature in **Settings → Profile**.

## Which signature gets used

When sending an email reply, dimmi picks the first enabled signature from this list:

1. **Per-address personal signature:** a teammate's signature for that specific support address (created through the REST API).
2. **Personal signature:** the teammate's default signature from **Settings → Profile**.
3. **Team signature:** the signature configured on the support address.

Replies from the dimmi agent only use the team signature. Any signature that is turned off is skipped.

## Reply style

- **Plain:** sends your reply text on its own (default).
- **Branded:** adds a thin bar in your brand color above the reply and a custom footer below it.

## Signature variables

Signatures support plain text without images and three variables:

- `{{member_name}}`: the replying teammate's name.
- `{{address_name}}`: the support address's display name.
- `{{company_name}}`: your workspace name.

If a variable has no value, dimmi drops its entire line. Because dimmi agent replies have no `{{member_name}}`, any line containing it is omitted automatically.
