# dimmi Go SDK

The Go SDK for [dimmi](https://github.com/dimmihq/dimmi). It does three things:

- Calls the REST API through a typed client generated from dimmi's OpenAPI document.
- Signs identity tokens so the messenger knows your signed-in users.
- Verifies dimmi's signed webhooks.

Go 1.22 or later.

```sh
go get github.com/dimmihq/dimmi-go
```

## REST API

```go
import (
	dimmi "github.com/dimmihq/dimmi-go"
	"github.com/dimmihq/dimmi-go/api"
)

client, err := dimmi.New(
	dimmi.WithToken(os.Getenv("DIMMI_TOKEN")),    // default: $DIMMI_TOKEN
	dimmi.WithWorkspace("ws_..."),                // default: $DIMMI_WORKSPACE
	dimmi.WithBaseURL("https://support.acme.com"), // self-hosted; default dimmi cloud or $DIMMI_BASE_URL
)

// One typed method per operation, named after its operationId.
res, err := client.API.ConversationsIndexWithResponse(ctx, nil)
for _, c := range *res.JSON200.Data {
	fmt.Println(c.Id, c.Subject)
}

// Any path, decoded into your own type.
var contact struct{ Data api.Contact }
err = client.Do(ctx, "POST", "/contacts", nil, map[string]any{"email": "ada@example.com"}, &contact)
```

Every request through the client:

- carries `Authorization: Bearer <token>` and the `Dimmi-Workspace` header;
- retries 429, 503 and dropped connections up to 3 times (`WithMaxRetries`), honouring `Retry-After`;
- sends an `Idempotency-Key` with each POST, reused by its own retries. To set your own key, use `dimmi.WithIdempotencyKey(ctx, key)` or the request editor `dimmi.IdempotencyKey(key)`.

### Errors

Error answers come back as `*dimmi.Error`, from generated calls too:

```go
var apiErr *dimmi.Error
if errors.As(err, &apiErr) {
	fmt.Println(apiErr.Status, apiErr.Code, apiErr.Message, apiErr.Fields["email"])
}
if errors.Is(err, dimmi.ErrNotFound) { ... }
```

The kinds you can match with `errors.Is`:

- `ErrBadRequest`
- `ErrUnauthorized`
- `ErrForbidden`
- `ErrNotFound`
- `ErrConflict`
- `ErrValidation`
- `ErrRateLimited`
- `ErrServer`

### Pagination

```go
// Cursor lists: follows meta.next_cursor.
it := dimmi.List[api.Conversation](client, "/conversations", url.Values{"limit": {"50"}})
for it.Next(ctx) {
	fmt.Println(it.Item().Id)
}
if err := it.Err(); err != nil { ... }

// Numbered pages: page=1, 2, ... until a short page.
all, err := dimmi.Pages[api.Audience](client, "/audiences", nil).All(ctx)
```

To add query parameters to a generated call, pass the `dimmi.Query(url.Values{...})` editor.

## Identity verification

Sign a short-lived token for the signed-in user. It uses the secret from Settings → Identity verification, or the private key whose public key you uploaded there.

```go
token, err := dimmi.SignIdentityToken(dimmi.User{
	ID: user.ID, Email: user.Email, EmailVerified: true, Name: user.Name,
	Company:    &dimmi.Company{ID: "acme", Name: "Acme"},
	Attributes: map[string]any{"plan": "pro"},
}, dimmi.IdentityOptions{}) // $DIMMI_IDENTITY_SECRET + $DIMMI_IDENTITY_KID, or $DIMMI_IDENTITY_PRIVATE_KEY
```

How a token is signed:

- With a shared secret, the token is HS256. The whole `dmi_idsec_...` string is the key.
- With a PKCS #8 PEM private key, it is ES256, RS256 or EdDSA, and `KeyID` is required.
- Tokens live 10 minutes by default and 1 hour at most.
- `Audience` and `Nonce` are optional.

To put the messenger on a page:

```go
html := dimmi.MessengerSnippet(dimmi.SnippetOptions{AppID: "wgt_...", Host: "https://app.trydimmi.com", Token: token})
```

Or let the messenger fetch fresh tokens from a route:

```go
http.Handle("/dimmi/token", dimmi.TokenHandler(func(r *http.Request) (*dimmi.User, error) {
	u := currentUser(r) // nil when nobody is signed in
	if u == nil { return nil, nil }
	return &dimmi.User{ID: u.ID, Email: u.Email}, nil
}, dimmi.IdentityOptions{}))
// and: dimmi.SnippetOptions{AppID: "wgt_...", Host: "...", IdentityURL: "/dimmi/token"}
```

## Webhooks

dimmi signs webhooks with [Standard Webhooks](https://www.standardwebhooks.com/). This SDK verifies them with the official library:

```go
wh, err := dimmi.NewWebhook(os.Getenv("DIMMI_WEBHOOK_SECRET")) // whsec_...
http.Handle("/dimmi/webhook", wh.Handler(func(r *http.Request, e *dimmi.Event) error {
	switch e.Type {
	case "conversation.created":
		var conv api.Conversation
		_ = e.DecodeObject(&conv)
	}
	return nil // an error answers 500, so dimmi retries
}))

// Or by hand, always over the raw body:
event, err := wh.Verify(body, r.Header) // errors.Is(err, dimmi.ErrWebhookVerification)
```

## Regenerating after API changes

`api/api.gen.go` is generated by [oapi-codegen](https://github.com/oapi-codegen/oapi-codegen), and is never committed in this repository (.gitignore): run `make sdk-generate` (or the script below) after cloning and after the API changes. The release splits `sdk/go`, generated code included, into the read-only mirror [`dimmihq/dimmi-go`](https://github.com/dimmihq/dimmi-go), tagged `vX.Y.Z`, which is why the module path is `github.com/dimmihq/dimmi-go`: `go get` needs the generated code, and a module path must match the repository that serves it.

```sh
cd sdk/go
scripts/generate.sh                                   # reads ../../tests/contracts/api_v1.openapi.json
scripts/generate.sh path/to/openapi.json              # or a file
scripts/generate.sh http://localhost:8080/api/v1/openapi.json   # or a running server
go test ./...
```

What the script does:

1. `scripts/openapi30` turns dimmi's OpenAPI 3.1 document into the 3.0 form oapi-codegen reads. A `type: [X, "null"]` becomes `type: X` plus `nullable: true`, and `contentMediaType` is dropped.
2. oapi-codegen (pinned in the script) writes `api/api.gen.go` from `api/oapi-codegen.yaml`.
3. The script builds the module.

Never break the public API. If the spec drops or renames something the SDK exposes, keep the old name as a `// Deprecated:` alias in a hand-written file under `api/`, so existing code still compiles.
