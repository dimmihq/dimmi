# Slack and GitHub integrations

The Slack and GitHub integrations are included on the Pro and Business plans.

## Slack

Connect Slack from **Settings**, then **Integrations**, then **Slack**. Lovelace posts a message to the channel you pick when a task is created, completed or reassigned, and you can create tasks from any Slack message with the **Create Lovelace task** shortcut.

## GitHub

Connect GitHub from **Settings**, then **Integrations**, then **GitHub**. Mention a task id such as LOV-123 in a branch name, commit or pull request and Lovelace links it to the task. Merging the pull request can move the task to Done automatically.
