# Naming: Dimmi

Researched 2026-11-01. Decision: **Dimmi**. Domain: **trydimmi.com**.

## TL;DR

- Dimmi = Italian "tell me". Warm, short, fits support.
- No one in support, chat, or AI agent space use name.
- npm `dimmi` free. Almost every GitHub org variant free.
- One real risk: Dimmi Health, Inc. pending US trademark in classes 9 and 42 (filed 2026-10-23, intent-to-use, health tracking software). Get trademark lawyer view before filing own mark.

## How we picked

Rules for candidates:

- No category words (chat, desk, help, support, AI, hub).
- No `-ly` / `-ify` endings.
- No names already used by dev tools (Knock, Courier, Relay, Speakeasy, Ahoy Rails gem).
- Each finalist checked: DNS + WHOIS on 5 TLDs, GitHub user/org, npm package, web search for companies, USPTO via Trademarkia.

### GitHub and npm

- npm `dimmi`: free. `dimmi-widget`, `dimmi-js`, `dimmi-sdk`, `@dimmi/widget`: free.
- GitHub free: `dimmihq`, `dimmi-hq`, `getdimmi`, `usedimmi`, `dimmi-dev`, `dimmi-oss`, `dimmichat`, `dimmilabs`.
- GitHub taken: `dimmi` (inactive user, 1 repo, 2012), `dimmish` (empty org, 2014).

### Downsides

- Pronunciation unclear at first (DEE-mee). Some read "dimmy", as in dim.
- Search results dominated by old Australian restaurant site for now.
